# 需求文档

## 1. 应用概述

### 1.1 应用名称
资源更新追踪系统

### 1.2 应用描述
用于管理剧集/动漫资源列表的Web工具，支持资源信息维护、自动变更检测、历史记录查询、显示格式自定义、第三方站点资源快捷检索绑定以及多站点（鸭影臻藏站点、不太灵站点等）资源同步与挂载，帮助用户高效追踪与发布资源更新状态。系统采用浅色系现代清爽主题，支持用户注册登录和管理员后台管理。

## 2. 用户与使用场景

### 2.1 目标用户
- 需要管理和追踪剧集/动漫资源更新的普通用户
- 需要将资源同步/挂载到第三方站点（如鸭影臻藏、不太灵站点）的内容发布者
- 负责系统管理和用户管理的管理员

### 2.2 核心使用场景
- 注册账号并登录系统
- 维护个人剧集资源清单与排序，通过快捷绑定搜索片源并回填信息
- 更新资源集数后快速获取格式化文本用于分享
- 查看资源修改历史记录
- 绑定第三方站点账号，搜索片源并直接挂载网盘资源，管理已发布资源列表
- 管理员管理用户、查看系统数据与配置系统参数

### 3.1 登录页

#### 3.1.1 登录表单
- 提供用户名/邮箱输入框
- 提供密码输入框
- 提供「登录」按钮
- 提供「还没有账号?去注册」链接，跳转至注册页

#### 3.1.2 教程按钮
- 在登录页面提供「教程」按钮
- 点击后在新窗口打开管理员设置的教程地址
- 教程地址从后端数据库读取
- 若管理员未设置教程地址，按钮置灰或隐藏

#### 3.1.3 邀请码按钮
- 在登录页面提供「邀请码」按钮
- 点击后弹出对话框，展示管理员设置的激活码获取信息
- 信息内容从后端数据库读取，支持多行文本展示
- 若管理员未设置邀请码信息，按钮置灰或隐藏

#### 3.1.4 登录验证
- 用户输入用户名/邮箱和密码后点击登录
- 系统验证账号密码是否正确
- 验证通过后跳转至资源管理主页
- 验证失败提示错误信息

### 3.2 注册页

#### 3.2.1 注册表单
- 提供用户名输入框
- 提供邮箱输入框
- 提供密码输入框
- 提供确认密码输入框
- 提供「注册」按钮
- 提供「已有账号?去登录」链接，跳转至登录页

#### 3.2.2 注册处理
- 用户填写完整信息后点击注册
- 系统验证信息格式和密码一致性
- 验证通过后创建账号并自动登录
- 跳转至资源管理主页

### 3.3 资源管理主页

#### 3.3.1 访问控制
- 未登录用户访问时自动跳转至登录页
- 已登录用户正常展示资源管理功能

#### 3.3.2 用户信息区域

##### 3.3.2.1 会员到期时间展示
- 在用户个人中心或侧边栏区域展示当前账号的会员到期时间
- 展示格式:「会员到期:YYYY-MM-DD」
- 若会员已过期，展示「已过期」

#### 3.3.3 资源列表管理区

##### 3.3.3.1 资源表格展示
- 展示当前登录用户的所有资源，每条资源包含以下字段:
  - 勾选框(用于标记已完结)
  - 资源名称(附带「快捷绑定」操作入口)
  - 链接
  - 集数
- 表格支持横向滚动查看所有字段

##### 3.3.3.2 快捷绑定功能
- 每条资源的「资源名称」后提供「快捷绑定」按钮
- 点击「快捷绑定」后弹出快捷绑定窗口
- 快捷绑定窗口包含:
  - 片源名称搜索输入框及搜索按钮
  - 搜索结果列表:展示站点站内片源库的匹配片源列表，每项展示片源名称、封面海报、类型等详细信息
- 用户在搜索结果中选中目标片源并点击「确定」后，系统自动将该片源的资源名称和网盘链接回填至当前资源的对应字段中
- 回填完成后自动保存并触发变更检测逻辑

##### 3.3.3.3 资源编辑
- 支持直接在表格中点击单元格编辑任意字段内容
- 双击集数单元格时，直接切换为原生输入框供用户输入数字修改集数
- 输入完成后(失去焦点或按回车键)直接保存修改
- 保留确认/取消逻辑，输入非法数字时进行校验并提示
- 编辑状态下全部内容正常渲染无截断
- 修改后触发自动变更检测机制

##### 3.3.3.4 资源拖拽排序
- 支持鼠标拖拽和触屏设备拖拽
- 用户可拖拽资源行调整顺序
- 拖拽完成后自动保存新顺序到后端数据库
- 排序结果持久化，刷新页面后保持用户设置的顺序

##### 3.3.3.5 资源新增
- 提供「新增资源」按钮
- 点击后弹出新增表单，包含以下输入项:
  - 文本输入框:用于粘贴资源描述文本
  - 链接输入框:用于粘贴资源链接
- 用户粘贴文本和链接后，系统自动解析并预填资源名称、集数与链接
- 用户确认或修改预填内容后点击保存，资源添加到列表

##### 3.3.3.6 资源删除
- 每条资源提供删除操作
- 点击删除后从列表中移除该条记录，并从数据库中永久删除

##### 3.3.3.7 已完结标记
- 用户可勾选资源列表中的资源
- 勾选后该资源标记为已完结状态，并同步展示到已完结片区
- 已完结标记持久化到数据库

#### 3.3.4 已更新栏

##### 3.3.4.1 日期切换按钮
- 在「已更新」标题后方提供三个日期切换按钮:今天、昨天、前天
- 默认选中「今天」按钮
- 点击对应按钮后，已更新栏仅展示对应日期的更新记录
- 今天=2026年9月12日更新的记录
- 昨天=2026年9月11日更新的记录
- 前天=2026年9月10日更新的记录

##### 3.3.4.2 自动变更检测
- 当用户修改资源列表中任意字段时，系统自动检测到变更
- 将该条资源的完整信息及更新时间存储到服务端数据库
- 已更新记录关联当前登录用户ID
- 支持同时修改多条资源，全部存储到服务端

##### 3.3.4.3 已更新记录展示与格式化
- 从服务端加载当前登录用户在所选日期的已更新记录
- 更换浏览器后仍可正常展示对应日期的已更新记录
- 提供格式切换选项:「完整格式」/「精简格式」
- 完整格式与精简格式均展示资源名称、更新集数与链接
- 提供「复制」按钮，点击将单条格式化文本复制到剪贴板
- 提供「清空已更新」按钮，点击清空当前所选日期的已更新记录

#### 3.3.5 已完结片区

##### 3.3.5.1 已完结资源展示
- 展示用户标记为已完结的资源列表
- 每条资源显示格式化文本(资源名称 + 集数 + 链接)
- 已完结资源从数据库加载，跨浏览器同步

##### 3.3.5.2 复制功能
- 提供「单个复制」按钮:复制单条已完结资源的格式化文本
- 提供「全部复制」按钮:复制所有已完结资源的格式化文本
- 提供「勾选复制」功能:用户勾选部分已完结资源后，点击按钮复制勾选资源的格式化文本

#### 3.3.6 修改历史记录

##### 3.3.6.1 历史记录查看与筛选
- 提供「查看历史」入口
- 展示当前登录用户的历史记录列表，每条记录包含修改时间、资源名称、修改字段名称、修改前后的值
- 提供时间范围筛选功能，支持按开始日期和结束日期筛选

#### 3.3.7 站点同步页

##### 3.3.7.1 标签页结构
- 包含四个标签页:盘链、观影站点、鸭影臻藏站点、不太灵站点
- 用户可切换标签页查看不同站点的同步与挂载功能

##### 3.3.7.2 盘链标签页
- 提供盘链站点的绑定功能
- 用户可将资源列表中的资源绑定到盘链站点

##### 3.3.7.3 观影站点标签页
- 提供观影站点的绑定功能
- 用户可将资源列表中的资源绑定到观影站点

##### 3.3.7.4 鸭影臻藏站点标签页
- 账号绑定:支持粘贴登录凭证完成绑定，服务端校验并持久化
- 网盘分享记录展示:展示当前绑定账号所分享的网盘资源信息(名称与链接)
- 绑定站点剧集:弹窗中支持关键词搜索片源(包含匹配、忽略大小写与多余空格、精准匹配置顶)，选择条目完成绑定与解绑

##### 3.3.7.5 不太灵站点标签页

###### 3.3.7.5.1 账号绑定与状态展示
- 账号状态区:展示当前是否已绑定不太灵站点账号以及绑定状态(已绑定/未绑定/已过期)
- 登录绑定表单(两步式绑定):
  - 用户名输入框
  - 密码输入框
  - 图形验证码展示区(展示算术算式图片)及点击刷新验证码能力
  - 验证码答案输入框
  - 「绑定/登录」按钮，提交后服务端通过代理接口换取凭证并持久化
- 解绑操作:支持用户主动解除与不太灵站点的绑定

###### 3.3.7.5.2 我的发布管理
- 列表展示:展示当前用户在不太灵站点已发布的网盘资源列表，包含资源标题、网盘类型、分享链接、提取码、发布时间
- 筛选功能:支持按网盘类型、资源标题关键词筛选发布记录
- 修改发布:支持修改已发布资源的标题、网盘链接、提取码
- 删除发布:支持删除指定已发布资源记录

###### 3.3.7.5.3 搜索片源并挂载资源
- 搜索影片:提供关键词搜索框，输入片名后查询站点影片列表(首屏展示匹配的影片封面、片名、豆瓣ID等信息)
- 挂载弹窗:
  - 用户点击搜索结果中的某部影片「挂载资源」按钮，系统自动通过豆瓣ID解析站点影片内部主键
  - 自动预填资源标题(默认采用影片名，允许用户追加规格后缀如4K/纯净版)
  - 提供网盘链接输入框供用户粘贴
  - 提供提取码输入框(可选)
  - 系统根据网盘链接自动识别并派生网盘平台类型
  - 用户点击「确认挂载」后，提交新增资源并在成功后自动刷新我的发布列表

## 4. 业务规则与核心逻辑

### 4.1 数据持久化
- 所有业务数据存储在后端数据库
- 用户表包含字段:用户名、邮箱、密码(加密存储)、注册时间、账号状态、角色、会员到期时间
- 资源表包含字段:资源名称、链接、集数、所属用户ID、已完结标记、排序顺序
- 历史记录表包含字段:修改时间、用户ID、资源名称、修改字段名称、修改前后的值
- 已更新记录表包含字段:用户ID、资源名称、链接、集数、更新时间(精确到日期)
- 鸭影凭证表存储鸭影臻藏站点的用户凭证与绑定关系
- 不太灵站点凭证表(`mukaku_tokens`)存储不太灵站点的用户凭证信息(用户ID、站点用户名、access_token、过期时间、更新时间)
- 系统设置表包含字段:教程地址(URL)、邀请码信息(多行文本)

### 4.2 快捷绑定与片源检索规则
- 快捷绑定搜索通过调用站内片源库搜索接口，检索的是站点全局片源库（包含片名、封面、类型、网盘链接等信息），非用户已发布的私有资源
- 用户确认选中后，直接覆盖或填入当前资源的资源名称与网盘链接字段，并触发字段变更检测记录

### 4.3 用户权限与生命周期规则
- 用户名和邮箱必须唯一，密码加密存储
- 第一个注册的用户自动成为管理员
- 普通用户仅可查看和操作属于自己的数据；管理员可管理全量数据
- 会员到期时间早于当前日期时，状态判定为「已过期」

### 4.4 变更检测与格式化规则
- 用户编辑资源字段并保存且值发生变化时，记录至服务端历史记录表与当前日期的已更新记录表
- 格式化文本规则:按「资源名称 更新至 第X集」换行拼接「链接:资源链接」

### 4.5 不太灵站点代理与鉴权规则
- 系统通过服务端代理中转不太灵站点所有接口请求，前端统一携带本系统用户身份凭据访问代理服务
- 登录流程必须经过算术验证码计算，验证码一次一换；登录成功后获取的JWT令牌有效期为7天(168小时)
- 不太灵站点无自动刷新凭据机制，Token过期后系统将凭证标记为已失效，并提示用户重新输入验证码登录绑定
- 用户的站点密码在任何环节均不持久化落库，仅保留换取的访问令牌

### 4.6 不太灵站点片源搜索与挂载规则
- 搜索影片接口返回首屏匹配列表(最多24条，不支持分页)
- 用户选择目标影片后，必须先通过该影片的豆瓣ID解析获取站点内部主键(`movies_id`)
- 网盘类型(`type`)由系统根据用户填写的网盘链接正则自动识别派生(支持baidu、ali、quark、115、lanzou、xunlei、uc、123、tianyi、guangya、other)，禁止直接填写字典ID或未转换的文本
- 新增挂载资源时，提交包含`movies_id`、`seed_name`、`link`、`code`及派生的`type`参数，提交成功后服务端回查验证并返回确认结果

## 5. 异常与边界情况

| 场景 | 处理方式 |
|------|----------|
| 快捷绑定搜索无匹配结果 | 弹窗列表展示空提示，允许用户重新输入片名搜索 |
| 快捷绑定选定片源缺少网盘链接 | 仅回填片源名称，网盘链接保持为空并提示用户补充 |
| 用户名或邮箱已存在 | 注册时提示用户名或邮箱已被使用 |
| 账号被禁用 | 登录时提示账号已被禁用，请联系管理员 |
| 未登录访问受保护页面 | 自动跳转至登录页 |
| 普通用户访问管理员面板 | 提示无权限访问 |
| 资源编辑值未改变 | 不触发变更检测，不记录历史 |
| 不太灵站点图形验证码输入错误或过期 | 提示验证码错误，自动重新获取并刷新验证码图片 |
| 不太灵站点账号或密码错误 | 提示第三方站点账号或密码错误，重置验证码 |
| 不太灵站点Token已过期(7天失效) | 提示站点登录态已失效，引导用户重新登录绑定 |
| 不太灵站点搜索片源无匹配结果 | 列表展示空状态，提示未找到相关影片 |
| 挂载资源时影片主键解析失败 | 提示无法获取影片详情主键，禁止提交挂载 |
| 挂载资源时网盘链接格式无法识别 | 自动归类为other类型并允许用户提交 |
| 修改/删除不太灵站点发布资源失败 | 提示操作失败及服务端返回的错误信息 |
| 拖拽排序保存失败 | 提示排序保存失败，界面恢复上一有效顺序 |

## 6. 验收标准

1. 用户打开应用，可通过登录页或注册页完成身份认证并进入资源管理主页
2. 用户在资源列表中点击资源名称后的「快捷绑定」按钮，弹出搜索窗口输入片名可检索到站内片源库的片名、封面海报和类型
3. 用户在快捷绑定弹窗中选中片源并确认后，系统自动将该片源的名称与网盘链接回填至资源列表对应字段并完成保存
4. 用户在用户信息区域可正常查看会员到期时间或过期状态
5. 用户新增或编辑资源后，系统自动检测变更并在已更新栏展示对应日期的格式化文本
6. 用户拖拽资源列表能够调整顺序，且刷新页面后顺序保持不变
7. 用户勾选资源后自动归入已完结片区，并支持单条、勾选或全部复制格式化文本
8. 用户进入站点同步页的不太灵站点标签页，点击获取算术图形验证码，输入账号、密码及算式答案后成功完成绑定
9. 用户在不太灵站点标签页中可查看当前账号已发布的网盘资源列表，并可执行修改和删除操作
10. 管理员可在后台管理用户账号、调整会员时长并配置系统教程与邀请码信息
