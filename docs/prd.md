# 需求文档

## 1. 应用概述

### 1.1 应用名称
资源更新追踪系统

### 1.2 应用描述
用于管理剧集/动漫资源列表的Web工具，支持资源信息维护、自动变更检测、历史记录查询、显示格式自定义、第三方全站点资源快捷检索绑定以及多站点（观影站点、鸭影臻藏站点、不太灵站点等）资源同步、自动发布与挂载，帮助用户高效追踪与发布资源更新状态。系统采用浅色系现代清爽主题，支持用户注册登录和管理员后台管理。

## 2. 用户与使用场景

### 2.1 目标用户
- 需要管理和追踪剧集/动漫资源更新的普通用户
- 需要将资源同步/自动发布/挂载到第三方站点（观影站点、鸭影臻藏、不太灵站点）的内容发布者
- 负责系统管理和用户管理的管理员

### 2.2 核心使用场景
- 注册账号并登录系统
- 维护个人剧集资源清单与排序，通过快捷绑定在接入站点中搜索片源，一键回填规范片名、多网盘链接并自动将资源发布/分享至目标站点影片下
- 更新资源集数后快速获取格式化文本用于分享
- 查看资源修改历史记录
- 绑定第三方站点账号，在同步页查看已发布资源列表并进行管理或独立挂载
- 管理员管理用户、查看系统数据与配置系统参数

### 3.1 登录页

#### 3.1.1 登录表单
- 提供用户名/邮箱输入框
- 提供密码输入框
- 提供「登录」按钮
- 提供「还没有账号?去注册」链接，跳转至注册页

#### 3.1.2 教程按钮
- 在登录页面提供「教程」按钮
- 点击后在新窗口打开管理员设置的教程地址
- 教程地址从后端数据库读取；若管理员未设置教程地址，按钮置灰或隐藏

#### 3.1.3 邀请码按钮
- 在登录页面提供「邀请码」按钮
- 点击后弹出对话框展示激活码获取信息（支持多行文本）
- 信息内容从后端数据库读取；若管理员未设置，按钮置灰或隐藏

#### 3.1.4 登录验证
- 用户输入账号密码后点击登录，系统验证通过后跳转至资源管理主页，验证失败提示错误信息

### 3.2 注册页

#### 3.2.1 注册表单
- 提供用户名、邮箱、密码及确认密码输入框
- 提供「注册」按钮与「已有账号?去登录」链接

#### 3.2.2 注册处理
- 校验信息格式与密码一致性，验证通过后创建账号并自动登录跳转至主页

### 3.3 资源管理主页

#### 3.3.1 访问控制
- 未登录用户访问时自动重定向至登录页

#### 3.3.2 用户信息区域
- 展示当前账号的会员到期时间，格式为「会员到期:YYYY-MM-DD」；若已过期则显示「已过期」

#### 3.3.3 资源列表管理区

##### 3.3.3.1 资源表格展示
- 展示当前用户的资源列表，字段包括：勾选框（标记已完结）、资源名称（含快捷绑定与发布入口）、链接、集数、第三方站点绑定与发布状态标识
- 支持横向滚动查看

##### 3.3.3.2 快捷绑定与自动发布功能
- 每条资源的「资源名称」后提供「快捷绑定」按钮，点击弹出弹窗
- 弹窗结构与能力：
  - **站点选择器**：支持切换所有已接入站点（观影站点、鸭影臻藏站点、不太灵站点）进行检索
  - **片源搜索框**：输入关键词并执行搜索，服务端对搜索词进行符号与年份归一化处理（支持包含年份如《冬城猎凶 (2026)》或纯片名的精准与模糊匹配）
  - **搜索结果列表**：展示目标站点片源库的匹配项（封面海报、完整资源名称、片源类型、匹配度标签、包含的各网盘资源类型及片源内部标识）
  - **回填与自动发布联动机制**：
    - 确认按钮提供「确认回填并发布」操作
    - **单链接场景**：系统将选中片源的规范完整名称、网盘链接回填至当前行；同时自动调用所选站点的发布资源API，将完整名称作为发布标题、网盘链接与提取码作为发布内容提交挂载到该片源下，成功后持久化绑定关系并提示发布结果
    - **多链接场景**：勾选多个网盘链接时，第一条链接回填当前行并调用接口发布至站点该片源下；后续选中的网盘链接按队列依次在当前行下方自动创建新资源行，每行均填入相同规范资源名称与对应网盘链接，并按队列串行调用目标站点发布API完成发布挂载，逐条触发保存、变更检测与状态更新

##### 3.3.3.3 资源编辑
- 支持直接在表格中点击单元格编辑任意字段
- 双击集数单元格直接切换为原生数字输入框，失焦或回车保存，输入非法字符时提示校验错误
- 修改后自动触发变更检测

##### 3.3.3.4 资源拖拽排序
- 支持鼠标与触屏拖拽资源行调整顺序，调整后自动保存并持久化

##### 3.3.3.5 资源新增
- 提供「新增资源」按钮，弹窗提供描述文本与链接输入框，系统自动解析并预填名称、集数与链接，保存后入库

##### 3.3.3.6 资源删除
- 每条资源提供删除操作，确认后永久移除

##### 3.3.3.7 已完结标记
- 支持勾选资源标记为已完结，数据实时同步至已完结片区并持久化

#### 3.3.4 已更新栏

##### 3.3.4.1 日期切换按钮
- 提供三个日期切换按钮：今天（2026年9月12日）、昨天（2026年9月11日）、前天（2026年9月10日），默认选中「今天」

##### 3.3.4.2 自动变更检测
- 资源列表中任意字段发生有效修改时，系统自动捕获并向数据库记录变更数据与更新日期，支持批量与多行队列更新

##### 3.3.4.3 已更新记录展示与格式化
- 支持「完整格式」与「精简格式」切换展示
- 提供「复制」按钮复制单条格式化文本，提供「清空已更新」按钮清空所选日期记录

#### 3.3.5 已完结片区
- 展示所有标记为已完结的资源列表（完整名称+集数+链接）
- 提供「单个复制」「勾选复制」及「全部复制」格式化文本功能

#### 3.3.6 修改历史记录
- 提供历史记录查询入口，支持展示修改时间、资源名称、修改字段、修改前后值，支持按开始/结束日期筛选

#### 3.3.7 站点同步页

##### 3.3.7.1 标签页结构
- 包含三个标签页：观影站点、鸭影臻藏站点、不太灵站点

##### 3.3.7.2 观影站点标签页
- 提供观影站点凭据绑定与状态管理
- 提供片源检索与网盘资源映射发布与绑定

##### 3.3.7.3 鸭影臻藏站点标签页
- 提供登录凭证绑定与服务端持久化
- 展示当前绑定账号分享的网盘记录列表
- 支持检索站点片源库并完成绑定/解绑/手动挂载发布

##### 3.3.7.4 不太灵站点标签页

###### 3.3.7.4.1 账号绑定与状态展示
- 展示当前绑定状态（已绑定/未绑定/已过期）
- 提供两步式绑定表单：用户名、密码、算术图形验证码（支持点击刷新）、算式答案输入框、「绑定/登录」按钮
- 提供解绑操作

###### 3.3.7.4.2 我的发布管理
- 列表展示当前账号已发布的网盘资源（标题、网盘类型、分享链接、提取码、发布时间）
- 支持按网盘类型与标题关键词筛选
- 支持修改已发布资源（标题、网盘链接、提取码）及删除发布记录

###### 3.3.7.4.3 搜索片源并挂载资源
- 搜索影片：关键词搜索站点片源库（展示封面、完整片名、豆瓣ID等），支持去除年份括号等容错检索
- 挂载弹窗：自动通过豆瓣ID解析站点影片内部主键(`movies_id`)，自动预填完整片名，提供网盘链接与提取码输入，系统自动识别网盘类型，确认挂载后调用站点发布接口入库并刷新我的发布列表

### 3.4 管理员面板
- **访问控制**：仅管理员账号可进入
- **用户管理**：用户列表查看、启禁用、设为管理员、修改会员时长
- **资源与历史查看**：跨用户查看全局资源列表与修改历史
- **系统设置**：教程URL与邀请码多行文本配置保存

## 4. 业务规则与核心逻辑

### 4.1 全站点站内片源检索支持与适配规则
- **站点片源库检索支持情况**：
  - **不太灵站点**：通过站点全局片源接口检索。服务端集成搜索词清洗机制（去除首尾书名号、提取核心词与年份别名），解决包含括号年份（如《冬城猎凶 (2026)》）检索为空的问题；带年份无结果时，自动降级为纯中文片名重试检索。
  - **鸭影臻藏站点**：支持站内全局片源检索接口，服务端执行模糊匹配、忽略大小写与空格去噪，优先置顶完全匹配项。
  - **观影站点**：支持通过站点片源检索API获取影视基础信息及关联资源。
- 快捷绑定窗口中可自由切换已接入站点，切换时动态载入对应站点的检索协议与发布凭证状态。

### 4.2 快捷绑定联动站点自动发布与回填规则
- **双向联动流程**：
  - 选定片源点击确认后，系统提取片源规范完整名称（包含主标题、季数、发布规格或副标题）。
  - 若用户在快捷绑定中选定目标站点且该站点已处于绑定登录状态，系统在本地回填资源数据的同时，自动提取网盘链接与提取码，并以规范完整名称作为「发布标题/资源名称」，调用目标站点对应的「发布网盘资源/挂载API」。
  - 站点发布成功后，系统在本地资源记录上打上该站点的绑定标记与外部片源ID，实现双向映射。
- **单链接回填与发布**：
  - 选定单一链接时，覆盖当前资源行，并向目标站点发起单次发布调用，返回成功后保存本地记录。
- **多链接队列回填与串行发布**：
  - 勾选多个云盘链接时，启用串行队列处理机制。
  - 队列第1条数据：覆盖当前聚焦行，填充规范完整名称与第1个云盘链接，并调用站点发布API发布第1条网盘资源。
  - 队列后续第2至N条数据：系统在当前行下方逐行创建新资源记录，填入相同规范完整名称及对应序号的云盘链接与集数，依次串行调用目标站点发布API将对应网盘资源挂载到该片源下。
  - 队列严格遵循前一条发布并持久化成功后再执行下一条的原则，防止高频并发导致第三方站点限流或写入错乱。

### 4.3 各站点发布契约与鉴权规则
- **不太灵站点**：发布前必须通过豆瓣ID或影片内部标识换取内部主键(`movies_id`)，自动正则识别网盘类型（baidu/ali/quark/115/lanzou/xunlei/uc/123/tianyi/guangya/other），提取分享链接与提取码，携带登录Token调用发布API；发布成功后同步刷新「我的发布」列表缓存。
- **鸭影臻藏站点**：携带用户已绑定的鉴权Token，以片源ID、完整标题、网盘URL及提取码为载荷调用对应站点的分享/挂载接口。

### 4.4 数据持久化与变更检测规则
- 资源表存储字段：资源名称、链接、集数、所属用户ID、已完结标记、排序顺序、各站点关联ID与发布状态。
- 用户表、历史记录表、已更新记录表、各站点凭证表及系统配置表由后端统一持久化存储。
- 资源字段值发生实质变化时记录历史表与已更新表；格式化文本规则为「资源名称 更新至 第X集」换行拼接「链接:资源链接」。

## 5. 异常与边界情况

| 场景 | 处理方式 |
|------|----------|
| 快捷绑定选定站点未绑定或登录态已失效 | 弹出提示需先前往站点同步页完成账号绑定，允许用户选择「仅本地回填」或取消操作 |
| 片名含特殊符号或年份导致检索无结果 | 自动清洗符号并以核心片名进行二次降级检索，展示匹配结果列表 |
| 快捷绑定选定片源未解析到网盘链接 | 仅回填完整资源名称，网盘链接保留为空，跳过自动发布并提示用户手动补充 |
| 自动发布到目标站点接口返回失败 | 中断当前及后续发布队列，保留已成功回填和发布的记录，在界面弹出明确错误提示（如：第三方站点资源已存在、Token过期等） |
| 多网盘链接队列回填中途某条失败 | 停止后续队列执行，已成功写入和发布的行予以保留，界面提示中断位置与失败原因 |
| 不太灵站点验证码错误或过期 | 提示验证码错误并自动刷新生成新的算术图形验证码 |
| 挂载资源时网盘类型无法识别 | 自动派生为 other 类型并允许继续发布提交 |
| 用户名/邮箱重复或账号被禁用 | 注册/登录时返回对应明确提示信息并阻止进入系统 |

## 6. 验收标准

1. 用户在资源列表中点击「快捷绑定」，弹窗站点下拉列表中可自由切换观影站点、鸭影臻藏、不太灵三个站点
2. 用户在快捷绑定中选择不太灵站点并输入《冬城猎凶 (2026)》或「冬城猎凶」，系统均能成功检索出对应的片源条目并展示完整名称与多网盘链接
3. 快捷绑定选中片源并确认回填时，系统不仅将规范完整名称和网盘链接回填至当前行，还自动调用所选站点的发布API将该资源挂载至目标影片下
4. 快捷绑定选定包含多个云盘链接的片源并全选时，系统按队列串行将第一条回填当前行并发布到目标站点，随后依次自动在下方插入新行回填其余链接并逐条完成站点发布
5. 用户在主页修改资源集数或信息后，系统自动捕获变更并在已更新栏对应日期下生成格式化文本
6. 用户在站点同步页可成功绑定不太灵站点的算术验证码登录，并能正常查看、修改和删除已发布网盘列表
7. 用户通过不太灵标签页搜索影片并填写网盘链接后，能成功解析影片主键并完成挂载发布
8. 管理员可在后台统一管理全量用户、调整会员时长并维护教程与邀请码信息

- 跨站点全网片源一键并行聚合搜索
- 批量跨站点资源一键同步发布
- 找回密码功能
